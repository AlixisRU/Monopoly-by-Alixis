# Мир-Монополия

Онлайн-настолка для друзей. Один файл `index.html`, сервер не нужен: игроки соединяются напрямую через WebRTC (PeerJS), а хостом становится тот, кто создал комнату.

## Как выложить на GitHub Pages

1. Создайте репозиторий на github.com, например `global-monopoly`.
2. Загрузите в него `index.html` и этот `README.md` (кнопка **Add file → Upload files**).
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Через 1–2 минуты игра откроется по адресу `https://ВАШ-ЛОГИН.github.io/global-monopoly/`.

## Как играть

1. Откройте ссылку, введите имя и нажмите **Создать комнату**.
2. Отправьте друзьям ссылку из центра поля (в ней уже есть код комнаты).
3. Когда все зашли, хост нажимает **Начать игру**.

Хост должен оставаться в игре, пока идёт партия. Если он закроет вкладку, игра прервётся.

## Правила этой версии

- 2–8 игроков. Стартовый капитал и бонус за Старт хост выбирает в лобби.
- Города собраны в 9 цветовых групп. С полной группой аренда удваивается, а дома и отели (до 5 уровней) строятся равномерно.
- Залог и выкуп объектов (выкуп стоит на 10% дороже), порты, налоги, клетки «Удача».
- Дубли дают дополнительный ход, три дубля подряд отправляют в тюрьму. Из тюрьмы можно выйти дублем, заплатив $50 или отсидев три хода.
- Долг можно покрыть залогом и продажей домов. Если денег не хватает даже после этого, игрок разоряется. Побеждает последний игрок.
- Чат внутри игры. Нажмите на клетку, чтобы увидеть аренду и управлять объектом.
