# Alixis's Monopoly Mod — V1.02 Dark Premium

Браузерная многопользовательская настольная игра с собственным интерфейсом в стиле Dark Premium. В V1.02 обновлён визуальный слой, добавлен экран выбора игрового поля и сохранена существующая игровая логика на Vanilla JavaScript + PeerJS.

## Что нового в V1.02

- Тёмно-синяя дизайн-система с золотыми и изумрудными акцентами.
- Новое лобби с созданием комнаты и подключением по коду.
- Экран выбора карты: **Standard Board** доступна; дополнительные карты обозначены как будущие.
- Стандартное поле 11 × 11 с 40 игровыми клетками.
- Новая игровая панель: игроки, объект, события и чат.
- Анимации интерфейса, кубиков, появления событий и фишек.
- Адаптивная раскладка для компьютеров, планшетов и телефонов.
- Сохранены существующие правила: броски, дубли, тюрьма, покупка, аренда, дома/отели, залог, налоги, удача, банкротство и чат.
- Сохранён сетевой протокол PeerJS и авторитетная роль хоста.

## Локальный запуск Windows

1. Распакуйте архив в отдельную папку.
2. Запустите `start.bat`.
3. Откройте `http://localhost:8000` — браузер откроется автоматически.
4. Не закрывайте окно консоли, пока используете локальный сервер.

Нужен Python 3. Если Python не установлен, откройте проект через другой локальный HTTP-сервер или опубликуйте на GitHub Pages.

## Публикация на GitHub Pages

1. Загрузите **содержимое** этой папки в корень репозитория.
2. Откройте **Settings → Pages**.
3. В Source выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/(root)`, затем сохраните.
5. Дождитесь публикации и откройте URL GitHub Pages.

Все пути к CSS и JavaScript относительные, поэтому проект поддерживает публикацию в репозитории вида `username.github.io/repository-name/`.

## Как играть

1. Откройте опубликованный сайт.
2. Введите имя. В блоке «Игровое поле» выбрана Standard Board (11 × 11, 40 клеток).
3. Нажмите «Создать комнату».
4. Отправьте друзьям код комнаты или скопируйте ссылку из верхней панели.
5. Другие игроки вводят код и нажимают «Войти».
6. После подключения минимум двух игроков хост нажимает «Начать игру».

## Сеть и ограничения

- PeerJS загружается с CDN, поэтому для сетевой игры нужен интернет.
- GitHub Pages раздаёт статические файлы; он не является игровым сервером.
- Создатель комнаты — хост и авторитетный узел игры. Он должен оставаться онлайн до конца партии.
- Если хост отключится, текущая партия прервётся. Передача хоста, переподключение и постоянное хранение партий пока не реализованы.
- На GitHub Pages сайт работает по HTTPS; PeerJS/WebRTC использует браузерное сетевое соединение.

## Проверка перед публикацией

- Убедитесь, что `index.html`, `css/` и `js/` лежат в корне репозитория.
- Проверьте создание комнаты и подключение со второго браузера/устройства.
- Проверьте чат, бросок кубиков, покупку и завершение хода.
- Если открывается старая версия, выполните жёсткое обновление страницы (`Ctrl + F5`).
