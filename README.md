# Alixis's Monopoly Mod

Браузерная многопользовательская настольная игра. Это первый этап рефакторинга исходного проекта: HTML, CSS и JavaScript разделены по файлам, а существующая игровая логика и сетевой протокол сохранены без намеренного изменения правил.

## Структура проекта

```text
Alixis-Monopoly-Mod/
├── index.html
├── start.bat
├── README.md
├── css/
│   └── main.css
└── js/
    ├── core/
    │   └── data.js       # общие помощники, клетки, состояние
    ├── engine/
    │   └── game.js       # игровая логика (на хосте)
    ├── network/
    │   └── peer.js       # создание комнаты, подключение, чат
    └── ui/
        └── render.js     # отрисовка поля и интерфейса
```

## Запуск на Windows

1. Распакуйте архив в отдельную папку.
2. Запустите `start.bat`.
3. Откроется `http://localhost:8000`. Окно консоли сервера должно оставаться открытым, пока вы играете.
4. Для игры с друзьями опубликуйте папку на GitHub Pages или другом статическом HTTPS-хостинге. `localhost` доступен только на вашем компьютере.

Для локального запуска нужен Python 3. Если его нет, можно открыть проект через любой локальный HTTP-сервер или опубликовать на статическом хостинге.

## Как играть

1. Введите имя и нажмите «Создать комнату».
2. Передайте друзьям код или ссылку комнаты.
3. Другие игроки вводят код и нажимают «Войти».
4. Хост начинает игру после подключения минимум двух игроков.

## Важные ограничения текущей версии

- PeerJS используется через CDN, поэтому для сетевой игры нужен доступ к интернету.
- Хост остаётся авторитетным узлом: если он отключится, текущая партия завершится.
- Переподключение игрока, передача хоста и постоянное хранение партий пока не реализованы.
- Это рефакторинг, а не полная переработка правил: существующие игровые ограничения и ошибки могут сохраняться и будут исправляться отдельными этапами.

## Проверка

Файлы JavaScript разделены на обычные browser scripts и должны подключаться в порядке, указанном в `index.html`. Не открывайте `index.html` через `file://` — используйте `start.bat` или HTTPS-хостинг.
