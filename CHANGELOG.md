# Changelog

## V1.02 — Dark Premium Visual Redesign
- Полностью обновлён визуальный стиль: тёмно-синий, золото и изумрудный.
- Переработан экран лобби: создание комнаты, подключение по коду и выбор карты.
- Добавлен реестр игровых карт; Standard Board — единственная доступная карта V1.02.
- Отображение Standard Board как поля 11 × 11 с 40 периметральными клетками.
- Переработана игровая панель, список игроков, карточка объекта, журнал событий и чат.
- Добавлены анимации появления интерфейса, броска кубиков, перемещения фишек и событий.
- Добавлена адаптивность и поддержка prefers-reduced-motion.
- Добавлена кнопка копирования ссылки комнаты.
- Сохранены существующие игровые правила и PeerJS-протокол.
- Обновлена документация и инструкции GitHub Pages.

## V1.0-refactor
- Переименован продукт в Alixis's Monopoly Mod.
- CSS вынесен в `css/main.css`.
- JavaScript разделён на data, engine, network и UI scripts.
- Порядок загрузки скриптов явно задан в `index.html`.
- Добавлен `start.bat` для локального запуска через Python HTTP server.
- Игровая логика и существующие обработчики оставлены без намеренного изменения.
